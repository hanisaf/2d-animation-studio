# Safadi Animation Studio 0.3.0 Release Notes

Version 0.3.0 introduces a first-class **Comics Creation Engine** alongside animation scenes, characters, locations, and arcade games. Comics use a two-stage pipeline—deterministic, code-rendered **Studio Edition** blueprints built from the project's shared character rigs and 3D sets, followed by optional **Gemini Nano Banana 2.1 Illustrated Editions**—paired with a native Studio comic reader, panel-by-panel viewer, headless PNG/PDF build tools, scaffolding templates, a 3-card landing page, and an agent skill.

## Comics engine and asset architecture

Comics follow the same self-contained folder and manifest architecture used by animation scenes and series:

- **Books and comic registry:** [`engine/books.js`](../engine/books.js) mirrors `engine/series.js` with `BOOKS`, `CURRENT_BOOK`, `book()`, `expandBooks()`, and `comicDir()`. Comics live under `comics/<book_id>/<comic_id>/`, where `book.js` defines trim size, art style prompt and `style_refs/`, defaults, and ordered `comics`. `registry.js`, `scripts/registry.mjs`, and `engine/timeline.js` expand `REGISTRY.books` into globally unique `REGISTRY.comics` and `REGISTRY.comicBook` entries, adding `ASSETS.comic`, `COMICS`, `COMIC_ILLUSTRATIONS`, `comic()`, `comicIllustrations()`, `comicDeps()`, `requireComic()`, and `reloadComicIllustrations()`.
- **Shared layout and lettering engine:** [`engine/comic.js`](../engine/comic.js) provides deterministic page geometry and comic drawing primitives, including `computePageLayout()`, `extractPageScript()`, `drawPageMasthead()`, `drawPanelFrame()`, `drawCaptionBox()`, `drawSpeechBubble()`, `drawComicSfx()`, `wrapLines()`, `roundedRectPath()`, `toPanelLocal()`, `drawImageCover()`, `drawImageContain()`, `drawLocationInPanel()`, and `renderComicPage()`.
- **Two-layer declarative panels:** Each panel separates visual painting (`draw(pw, ph)`) from declarative lettering (`lettering: { captions, bubbles, sfx }` or optional `drawLettering(pw, ph)`). Lettering coordinates accept normalized `(0, 1]` panel fractions, negative edge offsets, or literal pixels. This decouples lettering from runtime rig anchors so clean bubble-free panels can be exported for per-panel AI refinement, crisp vector frames and speech bubbles can be composited over illustrated art, and full-page prompts can extract verbatim dialogue automatically.
- **Canvas sizing and `W`/`H` isolation:** Comic rendering resizes the stage canvas to the comic's trim dimensions (for example, `1700×2200` Letter at 200 DPI) without mutating the animation engine's global `W = 1920` and `H = 1080` constants. `_trackCtx(X)` stays synchronized after resize, `studio/studio.css` parameterizes stage aspect ratio via `--stage-ar`, leaving comic mode cleanly restores `1920×1080` (`16 / 9`), and `drawLocationInPanel()` renders any 3D `LOCATIONS.*` set on a cached `1920×1080` offscreen canvas before cover-blitting it into a panel.
- **Typography:** `studio.html` and `studio/studio.js` load and preload `Fredoka` weights `500`, `600`, and `700` alongside `Luckiest Guy` so dialogue, captions, and SFX render consistently.

## Studio Comics UI and panel-by-panel viewer

`studio.html`, `studio/studio.css`, and `studio/studio.js` add native comic browsing, comparison, reading, and printing:

- **Sidebar navigation and cross-links:** A **Comics** section appears directly below **Scenes**, grouped by book in collapsible disclosures. Character and location views cross-link to the comics they appear in, and comic panels link back to their cast, locations, reference drawings (with lightbox), and inline `📄 Docs`.
- **Editions and reading modes:** Switch between **Studio (Code)**, **Illustrated (Gemini)**, and synchronized **Side by Side** (`#out-compare`), toggle **Fit Page** vs. scrollable **Fit Width**, toggle vector **Lettering**, and select among available takes when multiple takes exist.
- **Panel-by-panel view switcher:** Inspect a comic either as a **Full page** or one panel at a time using per-panel chips, `◀︎`/`▶︎` step controls, or by clicking directly on any panel in the full-page canvas. Keyboard shortcuts support `←`/`→`/`Home`/`End` across panels, `Esc` to return to Full page, and `⇧+←`/`⇧+→` across pages. Dynamic `--stage-ar` updates fit each panel's aspect ratio, and single-panel Illustrated and Side-by-Side views automatically crop the matching panel region from full-page illustrated PNGs when per-panel files are absent.
- **Deep linking, export, and printing:** URL parameters (`?comic=<id>&page=1&panel=1&view=...`) restore exact reading state. Actions include panel-aware **Snapshot PNG**, multi-page **Print / Save PDF** (`#comic-print` with `@media print` styling), and in-Studio **Refine with Gemini** (targeting the active panel in `panel` mode).
- **Headless render APIs:** `studio.html?render` exposes `setComic()`, `comicInfo()`, `renderComicPageDataUrl()`, and `renderComicPageTo()` for automated builds.

## Headless build and Gemini Nano Banana 2.1 pipeline

- **Headless comic builder:** [`scripts/build_comic.mjs`](../scripts/build_comic.mjs) (`npm run comic:build`) drives `studio.html?render` over an ephemeral loopback server to generate Studio page PNGs (`studio/page-XX.png`), borderless bubble-free per-panel PNGs (`--panels`), and multi-page trim-sized print PDFs (`--pdf` → `out/studio.pdf`, `out/illustrated.pdf`).
- **Gemini illustration pipeline:** [`scripts/illustrate_comic.mjs`](../scripts/illustrate_comic.mjs) (`npm run comic:illustrate`) calls Gemini Nano Banana 2.1 (`gemini-nano-banana-2.1`) in either full-page (`mode: 'page'`) or per-panel (`mode: 'panel'`) mode:
  - Enforces Gemini reference budgets (up to 4 book style references, 4 character references, and 14 images total, including the Studio blueprint).
  - Snaps page and panel dimensions to the closest supported Gemini aspect ratio (`1:1`, `2:3`, `3:2`, `3:4`, `4:3`, `4:5`, `5:4`, `9:16`, `16:9`, `21:9`, `1:4`, `4:1`, `1:8`, `8:1`), while `engine/comic.js` composites illustrated outputs with aspect-preserving `cover`/`contain` framing.
  - Caches inputs by SHA-1 in `illustrated/index.json`, retains historical takes in `illustrated/takes/`, promotes active/approved outputs (`--approve=<take_id>`), supports zero-cost `--dry-run` inspection, and automatically writes `illustrated/manifest.js` and updates `asset.js`.
- **Local Studio refinement API:** `serve.mjs` loads local `.env` credentials without exposing keys to the browser and adds `GET /api/capabilities` plus a hardened local-only `POST /api/illustrate-comic` endpoint (loopback and same-origin verification, allowlisted parameters, non-shell `spawn`, and a per-comic single-flight lock).
- **Git tracking hygiene:** `.gitignore` explicitly tracks book `style_refs/`, top-level comic source drawings, Studio PNG outputs (`studio/*.png`), active/approved `illustrated/*.png`, and `illustrated/manifest.js`, while ignoring regenerable `out/`, `illustrated/takes/`, and `illustrated/index.json`.

## Sami & Jenna: Ice Skating Adventure

The legacy `comics/ice-skating/` prototype and `scripts/build-ice-skating-comic.mjs` script were removed and migrated into the new book structure as [`comics/sami_and_jenna/`](../comics/sami_and_jenna/book.js) and [`Ice Skating Adventure`](../comics/sami_and_jenna/ice_skating/README.md):

- **Book setup:** Establishes the `sami_and_jenna` book (`Sami & Jenna Adventures`) with Letter trim (`1700×2200` at 200 DPI) and a tracked storybook style anchor (`style_refs/storybook_anchor_1.png`).
- **Two-page story (11 panels):** Combines **Page 1** (Panels 1–9: At Home, Mud Room, Front Doorway, Minnesota Ice Arena, Dip/Jump/Turn tricks, and Finale) with a new **Page 2** (Panels 10–11: a warm hug on the ice rink and a cozy fireplace homecoming), built from Jenna's hand-drawn `Original Drawing.jpg` and `Original Drawing 2.jpg`.
- **Dual editions:** Includes Studio Edition blueprints (`comic.js`, `studio/*.png`) built on the canonical `sami` and `jenna` rigs, alongside approved Gemini Illustrated pages (`illustrated/page-01.png`, `illustrated/page-02.png`, `illustrated/manifest.js`).
