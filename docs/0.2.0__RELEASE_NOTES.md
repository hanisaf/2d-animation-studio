# Safadi Animation Studio 0.2.0 Changes

Version 0.2.0 adds richer visual effects, camera movement, and dialogue animation; reduces rendering and standalone export costs; and improves Studio navigation. It also refines character artwork and model sheets.

## Visual engine and dialogue

The shared runtime gains five groups of visual features within the existing engine files:

- **Surface and compositing effects:** four animated 256×256 paper-grain tiles update at 12 fps, with a separate cached vignette. Scenes can tune `grain` and `vignette`. Seeded `withBoil(px, fn, seed)` isolates an object's line jitter from earlier drawing calls. `layer()` supports blend mode, alpha, and resolution controls; `bloom()` adds a reduced-resolution glow pass; `grade()` applies shot color before overlays.
- **Brush and motion tools:** `taperStroke()` and `sampleCurve()` support variable-width paths, `spring()` supplies damped motion, `trail()` draws sub-frame afterimages, and `smear()` draws a swept motion shape.
- **Lighting and shadows:** `withLight()` and `lit()` add ambient tint, directional rim light, and cel shading. `castShadow()` projects a subject silhouette onto the ground and can add glossy reflections while preserving the subject's returned anchors. Character previews can use a location's `light` configuration.
- **Camera and depth:** `persp()` accepts `yaw`, `pitch`, `roll`, and `lookAt`, with camera-space clipping. `P.billboard()` places screen-facing artwork in the scene, including camera roll. `depthStage(P)` sorts characters and props from far to near. Cameras without rotation retain the existing one-point projection path.
- **Dialogue animation:** `dialogueSyllables()` is shared by synthesized speech and callouts. `callout()` returns viseme and mouth information for `lipFlap()`, using dialogue timing or recorded envelopes. The Gemini TTS script generates compact 24 fps envelopes from decoded PCM and supports `--envelopes` and `--all-envelopes` for existing recordings. The mirroring lecture's `voice.js` is backfilled.

Brush and motion effects (M2) and lighting and shadows (M3) default to on. They can be controlled with the Studio checkboxes, `?m2=0&m3=0`, CLI flags `--no-m2 --no-m3`, standalone player options or `data-m2`/`data-m3` attributes, and per-scene `fx` settings. Studio stores its selection locally.

Raster effects and caches bypass the SVG path where appropriate; tapered strokes remain vector paths. Transparent exports omit paper grain and vignette. See [ANIMATION_GUIDE.md](../ANIMATION_GUIDE.md) for authoring APIs and controls.

## Rendering performance

The drawing hot path tracks affine transforms without allocating a `DOMMatrix` per shape, retaining a fallback for external contexts. Color parsing is cached. Speech bubbles reuse bounded text layouts and character widths, invalidate them when fonts load, and avoid repeated transforms for settled glyphs.

`staticLayer()` caches up to four backgrounds with baked blur and filters. Keys automatically include the scene, transform, effective feature flags, and layer settings; callers must include other visual inputs such as camera and set options. Scene selection clears the cache. Character previews reuse cached location backgrounds. Animated sets and boiling linework still require live drawing when their pixels change.

Blur resolution now ramps smoothly from full size at 0.5 px to half size at 1.5 px, avoiding abrupt changes during focus pulls. An explicit `scale: 1` forces full resolution. Shadow blur uses a half-resolution silhouette while subjects and directional lighting retain sharp buffers. Paper grain uses alpha `source-over` compositing instead of the more expensive `multiply` pass.

The throne room, soccer field, and family kitchen precompute static geometry and colors and batch repeated linework. Throne-room stained-glass artwork is cached while its shimmer stays animated; fountain jet paths are precomputed while droplets remain animated. Bitmap caches bypass vector/probe contexts where needed.

Studio character and location previews are capped at 24 fps. Scenes, movies, and standalone players skip redundant redraws according to their scene frame rate while explicit seeks and control changes still repaint.

## CLI and standalone exports

The CLI serves assets through an ephemeral local HTTP server and transfers frames, soundtracks, and video chunks as binary uploads, removing Base64 transfers from the main rendering pipeline. Workers reuse a page for metadata and audio instead of opening separate probe and encode pages.

`--build`, `--movie`, and `--clip` use parallel WebCodecs H.264 chunks, then concatenate and mux them with ffmpeg without re-encoding video. If the H.264 codec probe fails, the renderer falls back to parallel JPEG streams piped into ffmpeg. `--encoder=ffmpeg` selects that path explicitly; bitrate, CRF, and preset options control the appropriate encoder. The separate `--frames`, `--resume`, and `--encode` workflow remains available.

Standalone JavaScript exports include only required characters, locations, helper scenes, and transitive asset `uses`. Neptune, Princess Pearl, and Sami declare their cross-asset dependencies. Synthesized audio is compressed to AAC in MP4 where supported, with Opus in MP4 and WAV fallbacks. Each exported script downloads with a companion HTML test page.

Standalone players share font loading, support blob URLs and a Web Audio fallback for local-file audio playback, and release canvas buffers, font listeners, and bubble caches on `destroy()`.

## Studio navigation and character presentation

The sidebar uses native, non-exclusive `details` and `summary` disclosures. Character, location, series, arcade, and documentation groups initially collapse to keep navigation compact. Chevron and disclosure animations respect reduced-motion preferences. The page adds language and viewport metadata, a labeled navigation landmark, sequential section headings, and hidden decorative icons; stylesheet rules and event listeners replace inline styles and click handlers.

Model sheets show regular poses without `fight:` poses when regular poses exist. A shared layout keeps canvas and SVG sheets consistent, and preserved base dimensions prevent enlarged fighting bounds from shrinking regular poses. Individual fighting poses remain available in previews.

Jenna gains more detailed articulated pants, ribbed socks, enclosed pink sneakers, and layered tulle skirt artwork. Sarah gains refined hands and limb controls, wrist and shoe angles, optional arm layering, larger volleyball artwork, and more athletic setting and spiking cycles. Their asset documentation reflects the updated appearance and rig controls.

## Day on Ice showcase

[A Day on the Ice](../scenes/sami_shorts/scene76_day_on_ice/README.md) becomes a 69-second demonstration of the new effects and cameras. Its seven sequences cover a living-room invitation, mudroom preparation, first steps at the rink, a slalom glide, a low-angle jump, an orbital spin, and a father-and-daughter finale.

The scene adds a 3D arena with depth-sorted cones, benches, spectators, banners, rafters, and a hanging jumbotron. Camera orbits and rolls accompany tapered skate tracks, trails, jump smears, ice spray, bloom, directional shadows, ice reflections, and dialogue lip sync. Jenna's winter outfit and the scene's helmets, skates, scarf, and Fafy plush support the story.

## Recorded performance and validation

The [performance plan](0.1.0_PERFORMANCE_IMPROVEMENTS_PLAN.md#p2-follow-up-results-2026-11-24) records the final follow-up measurements on macOS with headless Chrome 158.0.8127.37 and CPU Canvas. These compare the P2 follow-up against saved pre-follow-up engine files, rather than against `main`:

| Scene | Before in ms per frame | After in ms per frame |
|---|---:|---:|
| Juggling | 43.45 | 27.92 |
| Offside Trap | 47.00 | 35.40 |
| Thanksgiving Feast | 34.63 | 26.20 |
| Day on Ice | 178.27 | 131.17 |

The same report records the grain pass improving from 7.37 to 1.00 ms per frame, with at most two channel levels of difference in sampled colors.

The branch adds `scripts/benchmark-paper-grain.mjs` and `scripts/test-performance-browser.mjs`, and updates JavaScript export, player-control, and SVG checks. Recorded passing checks cover cache invalidation and bounds, frame-order determinism, focus pulls, vector fallback, 606 SVG poses and model sheets, player cleanup, twelve fighter arenas, fighting-pose transforms, and a one-second CLI video with audio.
