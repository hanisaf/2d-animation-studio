# Safadi Studio Comics Engine — Design & Concrete Implementation Plan

## 1. Overview & Two-Stage Workflow

This plan expands `2d-animation-studio` to support first-class **Comics** alongside Scenes, Characters, and Locations, replacing and generalizing the `comics/ice-skating/` prototype.

The engine uses a **two-stage creative pipeline**:

1. **Stage 1 — Studio Edition (Code-Rendered Blueprint)**: Write the comic's story description, cast, locations, and page/panel script in `README.md` + `asset.js`, then build a deterministic, print-resolution comic in JavaScript using existing character rigs (`characters/`), sets (`locations/`), and a shared `engine/comic.js` layout/lettering library. Preview and iterate on framing, poses, outfits, expressions, and dialogue in a native **Comics** section inside `studio.html` at zero API cost.
2. **Stage 2 — Illustrated Edition ([Gemini Nano Banana 2.1](https://aistudio.google.com/docs/models/gemini-nano-banana-2.1))**: Once the Studio Edition blocking and storytelling are approved, feed the rendered Studio PNG(s) together with the book's style references and character reference art into [Gemini Nano Banana 2.1](https://aistudio.google.com/docs/models/gemini-nano-banana-2.1) (`gemini-nano-banana-2.1`, via the [Gemini API Image Generation](https://aistudio.google.com/docs/image-generation) endpoint) to produce a richly illustrated edition that faithfully preserves the exact poses, layout, and character likeness.

## 2. Locked Architectural Decisions

- **Books & Comics Mirror `series.js` & `scenes/`**: Group comics under `comics/<book_id>/<comic_id>/` with a `book.js` manifest (parallel to `scenes/<series>/series.js`). Comic IDs are globally unique across all books (`REGISTRY.comics`, `REGISTRY.comicBook`, `comicDir(id)`).
- **Two-Layer Declarative Panels (`draw` vs `lettering`)**: Separate panel art painting (`draw(pw, ph)`) from panel lettering (`lettering: { captions, bubbles, sfx }` or optional `drawLettering(pw, ph)`) so:
  - Clean bubble-free panels render directly from `draw(pw, ph)` with `lettering: false`.
  - Per-panel Illustrated mode composites crisp vector panel frames and lettering on top of Gemini PNGs without depending on character-rig anchors computed during Studio `draw()`.
  - Full-page Gemini prompts automatically extract exact verbatim dialogue, captions, and SFX from the declarative panel definitions.
- **Dual Refinement Modes (`mode: 'page' | 'panel'`)**:
  - **Full-Page mode**: Sends the full rendered Studio page PNG (with lettering) + book style refs + character refs to `gemini-nano-banana-2.1` for a cohesive illustrated page in one call.
  - **Per-Panel mode + Vector Lettering**: Renders each panel borderless without lettering (`lettering: false`), refines each panel individually at its closest supported aspect ratio, and composites it via aspect-fill (`cover`) center-crop inside vector frames with vector lettering on top.
- **Content-Hashed Caching & Clean Git Tracking**:
  - Cache historical takes by SHA-1 hash in `illustrated/takes/` and `illustrated/index.json` (gitignored so abandoned 2K/4K takes never bloat the repository).
  - Track **studio picture outputs (`studio/*.png`)**, **active/approved `illustrated/*.png`**, `illustrated/manifest.js`, `comics/<book>/style_refs/`, and top-level comic source `refs` in git. Ignore regenerable `out/`, `illustrated/takes/`, and `illustrated/index.json`.
- **Legacy Cleanup on Migration**: Once `comics/ice-skating/` is migrated to `comics/sami_and_jenna/ice_skating/` (preserving `Original Drawing.jpg` and seeding `illustrated/page-01.png` + `illustrated/manifest.js` + `style_refs/`), delete legacy `comics/ice-skating/` and `scripts/build-ice-skating-comic.mjs`.
- **Landing Page Visibility**: Add **Comics** as a full third card (`Movies · Comics · Games`) on `index.html`, linking directly into the Studio's Comics view (`studio.html?comic=ice_skating`).


### 4.2 `comics/<book_id>/<comic_id>/asset.js`

```js
asset({
  title: 'Ice Skating Adventure',
  logline: 'Jenna teaches Dr. Sami to glide, dip, jump, and turn at the Minnesota rink.',
  cast: ['sami', 'jenna'],
  locations: [],                                // ONLY registered LOCATIONS ids actually drawn by comic.js
  files: ['comic.js'],
  docs: 'README.md',
  refs: ['Original Drawing.jpg'],
  illustrated: 'illustrated/manifest.js',       // optional; written/updated automatically by illustrate_comic.mjs
  illustration: {
    model: 'gemini-nano-banana-2.1',
    mode: 'page',                               // 'page' | 'panel'
    resolution: '2K',                           // '1K' | '2K' | '4K'
    stylePrompt: '',                            // optional chapter override appended to book.style.prompt
    thinkingLevel: 'medium',                    // 'minimal' | 'medium' | 'high'
  },
});
```

> **Rule on `locations`**: `comicDeps()` loads every ID in `asset.locations` from `REGISTRY.locations`. Only list registered `LOCATIONS` IDs that `comic.js` actually calls (e.g., `ice_skating` paints its own 2D panel backgrounds inline, so `locations: []` unless refactored to call `LOCATIONS.living_room`).

> **Rule on `illustrated`**: To avoid 404 console errors and preserve `file://` compatibility, `studio.html` only loads `illustrated/manifest.js` when `asset.js` declares `illustrated: 'illustrated/manifest.js'`. `scripts/illustrate_comic.mjs` writes `illustrated/manifest.js` and ensures `asset.js` points to it.

### 4.3 `comics/<book_id>/<comic_id>/comic.js`

```js
comic({
  // width, height default from book.size
  paper: '#FFFDF7',
  margin: 52,
  gutter: 20,
  pages: [
    {
      id: 'page-01',
      masthead: {
        title: 'SAMI & JENNA: ICE SKATING ADVENTURE!',
        subtitle: 'Featuring Fafy the Giraffe · Based on Jenna’s Original Comic',
      },
      rows: [
        {
          height: 378,
          panels: [
            {
              id: 'p1_at_home',
              weight: 1,                        // or explicit pixel `width`
              cast: ['sami', 'jenna'],          // optional per-panel cast for Gemini 4-character ref budgeting
              prompt: 'Cozy warm living room with sunny snowy window.',
              draw(pw, ph) {
                // Studio Canvas art ONLY (background, props, characters)
              },
              lettering: {
                captions: [
                  { text: 'AT HOME', x: 14, y: 14, size: 22 },
                ],
                bubbles: [
                  { speaker: 'sami', text: 'Jenna, should we go on a walk?', cx: 0.82, cy: 0.23, tx: 0.63, ty: 0.42, size: 23, maxW: 310 },
                ],
                sfx: [],
              },
              // Optional hook for custom vector lettering:
              // drawLettering(pw, ph) { ... }
            },
          ],
        },
      ],
    },
  ],
});
```

- **Coordinate convention in declarative `lettering`**: Numeric coordinates in `(0, 1]` for `cx`, `cy`, `tx`, `ty`, `x`, `y` are normalized panel fractions (`pw * v`, `ph * v`); values `> 1` (or `<= 0` when negative offsets are not normalized) are literal panel pixels.
- **Zero coupling between `draw` and `lettering`**: Because `lettering` does not depend on runtime return values from `draw()`, per-panel Illustrated mode can draw the Gemini PNG and overlay crisp vector frames + bubbles + captions + SFX identically.

## 5. Technical Design Details & Edge Cases

### 5.1 Canvas Sizing & `W`/`H` Isolation
- `engine/core.js` defines `const W = 1920, H = 1080` as global constants used by `persp()`, `layer()`, `bloom()`, `castShadow()`, `grade()`, and `drawPaperFinish()`.
- **Do not mutate `W` or `H`.** Instead:
  - `engine/comic.js` uses `comicDef.width` / `comicDef.height` explicitly, sets `canvas.width` / `canvas.height` for comic rendering, and calls `_trackCtx(X)` so affine transform tracking stays synchronized after canvas resize.
  - `studio/studio.css` replaces hardcoded `16 / 9` on `#out` with a CSS variable `--stage-ar: 16 / 9`.
  - `studio/studio.js` sets `--stage-ar` to `${comic.width} / ${comic.height}` in comic mode, and **explicitly restores** `canvas.width = W; canvas.height = H; X = canvas.getContext('2d');` and `--stage-ar: 16 / 9` whenever leaving `mode === 'comic'`.
  - `engine/comic.js` exposes `drawLocationInPanel(pw, ph, render1080pFn)` that renders any 3D `LOCATIONS.*` view onto a cached `1920×1080` offscreen canvas (where `persp()` projects around `W / 2 = 960`) and cover-blits it cleanly into `(pw, ph)`.

### 5.2 Gemini Nano Banana 2.1 API Integration Contract
- **Endpoint**: `POST https://generativelanguage.googleapis.com/v1beta/models/${model}:generateContent` with header `x-goog-api-key: $GEMINI_API_KEY`.
- **Payload configuration**:
  ```json
  {
    "contents": [{ "role": "user", "parts": [ ...inlineDataParts, { "text": "..." } ] }],
    "generationConfig": {
      "responseModalities": ["IMAGE"],
      "imageConfig": {
        "aspectRatio": "3:4",
        "imageSize": "2K"
      }
    }
  }
  ```
- **Reference image budget enforcement** (14 images max total):
  - Slot 1: Studio blueprint PNG (page or clean panel).
  - Style slots: `book.style.refs` (up to 4).
  - Character slots: Cast refs from `characters/<id>/asset.js` `refs`, scoped to panel/page `cast` when specified, **capped at 4 character references** (matching Nano Banana 2.1's 4-character identity limit), with a clear console warning if truncated.
  - Remaining slots (up to total 14): optional comic-level `refs` if explicitly opted in.
  - MIME detection supports `.png`, `.jpg`/`.jpeg`, and `.webp` (used by several existing character assets).
- **Discrete aspect-ratio snapping & cover compositing**:
  - Supported Gemini ratios: `1:1`, `2:3`, `3:2`, `3:4`, `4:3`, `4:5`, `5:4`, `9:16`, `16:9`, `21:9`, `1:4`, `4:1`, `1:8`, `8:1`.
  - `pickAspectRatio(w, h)` chooses the supported ratio minimizing `|log((w / h) / (rw / rh))|`.
  - `engine/comic.js` composites illustrated pages and per-panel outputs using `drawImageCover(ctx, img, x, y, w, h)` (aspect-preserving center-crop) so mismatched ratios (`1700×2200` vs `3:4`, wide `1596×378` banner vs `4:1`) never stretch characters.
- **Mode-specific prompting**:
  - `page` mode: Combines `book.style.prompt` + `asset.illustration.stylePrompt` + strict composition/pose/likeness instructions + **verbatim dialogue, caption, and SFX text** extracted from the page's panels so lettering stays accurate.
  - `panel` mode: Combines `book.style.prompt` + `asset.illustration.stylePrompt` + `panel.prompt` + strict instruction for a **full-bleed illustration with zero panel borders, zero speech bubbles, zero captions, and zero text**.

### 5.3 Local Studio Refinement API (`serve.mjs`)
- Zero-dependency `.env` loader in `serve.mjs` (fills `process.env.GEMINI_API_KEY` only if not already set in environment; key is never returned to the browser).
- `GET /api/capabilities` → `{ local: true, geminiConfigured: boolean }`.
- `POST /api/illustrate-comic` with JSON body `{ comicId, page, panel, mode, force }`:
  - Allowed only on loopback (`127.0.0.1` / `localhost`) with same-origin `Host`/`Origin` verification (blocks cross-origin browser tab CSRF).
  - Validates `comicId` against `REGISTRY.comics`, integer `page`/`panel`, enum `mode`, boolean `force`.
  - Per-comic in-memory lock (`409 Conflict` while a refinement is in flight).
  - Spawns `node scripts/illustrate_comic.mjs ...` directly via `child_process.spawn` (never shell-interpolated).
  - Returns JSON `{ ok, generated, cached, error, log }`.
- In `studio.html`, **Refine with Gemini** queries `/api/capabilities` on demand; when opened via `file://`, static hosting, or without `GEMINI_API_KEY`, the button is cleanly disabled with an informative tooltip.
