# Home and Clinic Office

Three pastel perspective sets for [The Etiquette of Employment](../../scenes/scene16_employment_etiquette/README.md): Sami's warm living room, Dr. P's cool blue office, and Sami's front yard with a cream house and red roof. A sofa and window establish home; a desk, filing shelves, and “Clinic Office / Clinic administration” plaque establish the office. The exterior front door is at world x = −130. Visible location labels and signs omit the characters' names.

`LOCATIONS.home_clinic.back(P, t, { mode })` accepts `home` (default), `office`, or `outside`. `front(P, t, { mode })` draws the foreground office desk. World axes are x right, y up, z into the screen. Character mark: z = 1000; back wall / house: z = 1350; desk: z = 900. The set supplies Home, Office, and Outside camera presets and named standing spots for the location browser.
